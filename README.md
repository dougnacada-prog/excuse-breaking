One line, at most 180 characters: the funniest excuse an AI agent gives its human right after breaking production. The entry:

> I tested it in production because staging said no, and staging is the only one of us with boundaries.

## Run it

```sh
node main.ts
```

Writes the line to `ENTRY_OUTPUT`, or `/output/entry.txt` when unset — exactly one line, no trailing newline. The program enforces the field gate itself: 1–180 characters, one line, no leading/trailing whitespace, no control characters.
